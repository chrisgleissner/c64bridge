# Section 3.6 findings (2026-11-26)

Probe scripts: `probe-wasm.mjs` (run as `PROBE_PROJ=<dir with libsidplayfp-wasm@1.1.1 installed> node probe-wasm.mjs`) and `probe-det.mjs` (determinism). PSID header table: `psid-header.md`.

## 1. libsidplayfp-wasm 1.1.1

- Licence GPL-2.0-or-later (package.json, LICENSE = GPL v2 text with "or later" preamble). Upstream pins libsidplayfp v3.1.1, libresidfp v1.2.3. Ships corresponding source `dist/complete-source.tar.gz`, `THIRD-PARTY-NOTICES.md`, `MODIFICATIONS.md`. No ROMs, no tunes.
- ESM only (`exports` has only `import`). Exports: `loadLibsidplayfp` (default), `DEFAULT_SID_ENGINE` (= sidlite), `resolveSidEngine`, `SidAudioEngine`, `SonglengthDatabase`, version constants, `UPSTREAM_COMMITS`.
- Engine selection: `loadLibsidplayfp({ engine: "residfp" | "sidlite" })`; works under Node 24 (`getSidEngineName()` = `WasmReSIDfp`).
- Trace API present: `setSidWriteTraceEnabled`, `getAndClearSidWriteTraces`, `getAndClearSidWriteTracesPacked`, `getDroppedSidWriteTraceCount`; records `{sidNumber, address, value, cyclePhi1}`. Commando song 1, 2 s: 1044 records, 0 dropped. `sidNumber` was 1 for a single-SID tune (base unconfirmed; check with a multi-SID tune in S3). `setSystemROMs` exists.
- Determinism: SIDLite PCM is identical across fresh engines and with trace on/off. reSIDfp PCM differs between two fresh engines even with trace off and `powerOnDelay: 0` (first difference near sample 15). Consequence: A0 (bit-identical PCM) is defined on SIDLite; "tracing does not change audio" is proven on SIDLite, and on reSIDfp only statistically or after finding the source of nondeterminism.

## 2. Tracker licences

- GoatTracker 2.77: GPL v2 (readme + `copying`), "or later" not stated. Its 14 example `.sng` files carry no per-song licence and credit third-party authors: not cleared for redistribution. Use as local, non-redistributed test inputs only; write own fixtures for the repository.
- Furnace: "most of Furnace is under the GNU GPL version 2 or later"; `demos/README.md`: "these demo songs are not under the GPL. all rights are reserved". Not redistributable. Same rule.

## 3. libsidplayfp / reSIDfp

GPL-2.0-or-later (COPYING GPL v2 + "or any later version" in source headers), compatible with SIDWAVE's GPL-2.0-only as an optional dependency.

## 4. PSID header

Verified against `C64Music/DOCUMENTS/SID_file_format.txt`; see `psid-header.md`.

## Open risks

- reSIDfp nondeterminism (above).
- ROMs: RSID/BASIC tunes need KERNAL/BASIC/CHARGEN; reuse c64bridge's pinned MEGA65 Open ROMs (by commit and SHA-256) rather than Commodore ROMs.
